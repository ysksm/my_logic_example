TCPからHTTPを自作する

ライブラリを一切使わず、Node.js の net モジュール（＝生のTCPソケット）だけで HTTPサーバを1行ずつ組み立てていきます。最終目的は CORS を深く理解すること。 全19ステップ、1ステップにつき新しい概念はひとつだけです。

進め方
  1. スライドを開いて「今日わかること」を読む
  2. steps/stepNN-*/ で node server.js を起動する
  3. スライドの「手を動かす」に従って curl やブラウザで叩く
  4. サーバのコンソールに流れる生のHTTPテキストを読む（これが一番大事）
  5. server.js を開いて、前のステップからの差分を確認する
  6. 最後のクイズに答えてから次へ
必要なもの
  • Node.js 18 以上（node -v で確認）— 依存パッケージのインストールは不要です
  • curl（macOS / Linux には標準で入っています）
  • Google Chrome — 第4章以降の CORS 実験で DevTools の Network タブを使います

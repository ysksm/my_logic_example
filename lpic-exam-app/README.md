# lpic-exam-app — LPIC 章別演習アプリ

LPIC（LPIC-1 101 / 102）の受験対策用に、**章を指定して問題を解き、正解率を記録し、間違えた問題だけを繰り返せる** Ruby on Rails アプリです。

- Rails 8.0 / Ruby 3.3 / SQLite / Hotwire（Turbo + Stimulus）/ Propshaft
- ログイン機能なしの **個人向けシングルユーザ** 構成（ローカルで動かす前提）
- 問題データは YAML（`db/seeds/questions/*.yml`）で管理。**42 章・139 問**を同梱

---

## 1. 仕様

### 1.1 やりたいこと（要件）

| # | 要件 | 実現方法 |
|---|---|---|
| R1 | 章を指定して問題を解く | 章別演習モード。章は複数選択可、出題数・並び順を指定 |
| R2 | 正解率を見る | セッション単位／章単位／試験単位／日別で集計 |
| R3 | 間違った問題だけ再度解く | ①そのセッションの間違い ②直近の解答が不正解の問題 ③一度でも間違えた問題 の3通り |

### 1.2 ドメインモデル

```
Exam（試験: 101-500 / 102-500）
 └─ Chapter（章: 101.1, 103.2 ... LPIC の主題番号）
     └─ Question（問題: 単一選択 / 複数選択）
         └─ Choice（選択肢: correct フラグを持つ）

QuizSession（演習セッション: 出題条件・状態・開始/終了時刻）
 └─ QuizItem（出題1件: 選んだ選択肢・正誤・解答時刻）
```

- 解答履歴は `QuizItem` にすべて残る。正解率はここから集計するので、**別途カウンタを持たない**（二重更新によるズレが起きない）
- `QuizSession#source_quiz_session` で「どのセッションの復習か」を辿れる
- `Question#code`・`Chapter#code` は一意。seed は code をキーにした upsert なので、**問題を追加・修正しても解答履歴は壊れない**

### 1.3 出題モード

| モード | 対象となる問題 | 用途 |
|---|---|---|
| `chapter` 章別演習 | 選択した章（未選択なら試験全体） | 学習中の章を集中的に |
| `exam` 模擬試験 | 試験全体からランダム | 本番前の総合演習 |
| `review_wrong` 苦手問題の復習 | `last`: 直近の解答が不正解 ／ `ever`: 一度でも間違えた | **R3** の中心機能 |
| `review_session` セッションの復習 | 指定セッションで間違えた問題 | 結果画面の「間違えた N 問だけもう一度」 |
| `unattempted` 未挑戦 | まだ一度も出題されていない問題 | 取りこぼし防止 |

共通オプション: **出題数**（1〜200）／**並び順**（ランダム / 章・問題番号順）。

### 1.4 正解率の定義

2種類を使い分けています。

- **通算正解率** = 正解した解答数 ÷ 解答数。同じ問題を何度解いてもすべて分母に入る（学習の履歴）
- **最新正解率** = 問題ごとに「最後の解答」だけを見た正解率（＝**いまの実力**）

「苦手問題の復習」の既定である `last` は後者の考え方で、**一度間違えても正解できるようになった問題は復習キューから自動的に外れます**。

### 1.5 画面

| 画面 | パス | 内容 |
|---|---|---|
| ダッシュボード | `/` | 通算正解率、復習ボタン3種、進行中セッション、試験別進捗、苦手な章 TOP5、最近の結果 |
| 試験一覧 / 詳細 | `/exams`, `/exams/:code` | 主題ごとに章を並べ、章別の正解率と「解く」ボタン |
| 章詳細 | `/chapters/:code` | 章の正解率、その章の全問題と直近の正誤 |
| 演習作成 | `/quiz_sessions/new` | モード・試験・章（複数選択）・出題数・並び順の指定 |
| 出題／採点 | `/quiz_sessions/:id/q/:item_id` | 1問ずつ出題 → 即時採点 → 正誤と解説を表示 → 次へ |
| 結果 | `/quiz_sessions/:id/result` | 正解率・所要時間・章別内訳・全問の振り返り・**間違いだけ復習** |
| 履歴 | `/quiz_sessions` | 過去セッション一覧、再開・復習・削除 |
| 問題バンク | `/questions` | 章・状態（間違えた／未挑戦）・キーワードで検索して解説を読む |
| 成績 | `/stats` | 試験別・章別・直近14日の推移 |

### 1.6 解答フローの仕様

1. 出題は1問ずつ。解答すると**その場で正誤と解説**が出る（まとめて採点しない）
2. 解答済みの `QuizItem` は再採点されない（ブラウザの戻る・二重送信で結果が変わらない）
3. 選択肢を選ばずに送信した場合は採点せずエラー表示
4. 複数選択問題は**過不足なく一致**した場合のみ正解
5. 全問解答すると自動的に `finished` になり結果画面へ。途中で「ここまでで終了する」も可能（未解答分は集計対象外のまま残り、あとから再開できる）

## 3. 問題データの追加・編集

問題は `db/seeds/questions/*.yml` に定義します。ファイルは主題（101〜110）ごとに分かれています。

```yaml
exam_code: "101-500"          # db/seeds/exams.yml の code を参照
chapters:
  - code: "101.1"             # 章コード（一意）
    name: "ハードウェア設定の決定と構成"
    description: "..."
    position: 1011            # 表示順
    questions:
      - code: "101.1-01"      # 問題コード（一意・これが upsert のキー）
        body: "PCI デバイスの一覧を表示するコマンドはどれか。"
        kind: single          # single（単一選択） / multiple（複数選択）
        difficulty: 1         # 1=易 2=普通 3=難
        explanation: |
          lspci は PCI バス上のデバイスを一覧表示する。
        choices:
          - body: "lspci"
            correct: true
          - body: "lsusb"     # correct 省略時は false
```

追記したら `bin/rails db:seed` を再実行します。`code` をキーにした upsert なので、

- 既存問題の本文・選択肢・解説の修正 → 反映される（**解答履歴は保持**）
- 新規問題の追加 → 追加される
- 正解の選択肢が1つも無い問題があると、その場でエラーになる（データ不備の検知）

問題を出題対象から外したいときは、DB 上で `questions.active` を `false` にします。

### 同梱データ

| 試験 | 主題 | 章数 | 問題数 |
|---|---|---|---|
| 101-500 | 101 システムアーキテクチャ／102 インストールとパッケージ管理／103 GNU と Unix コマンド／104 デバイス・ファイルシステム・FHS | 23 | 76 |
| 102-500 | 105 シェルとスクリプト／106 ユーザーインターフェイス／107 管理業務／108 重要なシステムサービス／109 ネットワークの基礎／110 セキュリティ | 19 | 63 |

単一選択 123 問、複数選択 16 問。

章の構成は LPIC-1 v5.0 の主題番号に対応させています。問題は学習用に作成したもので、本試験の問題ではありません。

## 4. 主なファイル

```
app/models/
  quiz_builder.rb     出題条件 → QuizSession/QuizItem を組み立てるファクトリ
  stats.rb            解答履歴から正解率を集計するクエリオブジェクト
  quiz_session.rb     セッションの進捗・正解率・章別内訳
  quiz_item.rb        1問の解答と採点（grade!）、latest_per_question スコープ
  question.rb         採点ロジックと復習用スコープ（last_answer_wrong / ever_wrong / unattempted）
app/controllers/      dashboard, exams, chapters, quiz_sessions, quiz_items, questions, stats
db/seeds/             exams.yml と questions/*.yml（問題データ）
test/                 モデルテスト + 統合テスト
```

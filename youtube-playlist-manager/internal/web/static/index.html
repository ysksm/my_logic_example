      設定

      環境変数 YOUTUBE_API_KEY で設定する方法

      環境変数はこの画面で保存したキーより優先され、データファイルには保存されません。設定後はアプリを起動し直してください。

      macOS / Linux（ターミナル）

      その場で 1 回だけ使う:

      YOUTUBE_API_KEY=AIza... ./youtube-playlist-manager

      毎回使う（zsh。bash は ~/.bashrc）:

      echo 'export YOUTUBE_API_KEY=AIza...' >> ~/.zshrc
source ~/.zshrc
./youtube-playlist-manager

      Windows（PowerShell）

      その場で 1 回だけ使う:

      $env:YOUTUBE_API_KEY = "AIza..."
.\youtube-playlist-manager-windows-amd64.exe

      毎回使う（設定後、PowerShell を開き直す）:

      setx YOUTUBE_API_KEY "AIza..."

      Windows（コマンドプロンプト）

      set YOUTUBE_API_KEY=AIza...
youtube-playlist-manager-windows-amd64.exe

      解除するには、macOS / Linux は unset YOUTUBE_API_KEY（シェル設定ファイルの行も削除）、Windows は [Environment]::SetEnvironmentVariable("YOUTUBE_API_KEY", $null, "User") を実行します。

      既定は 10,000 units / 日。リセットは太平洋時間 0 時（日本時間 16〜17 時）。

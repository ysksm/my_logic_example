URL の扱い・ルーティング・CORS

URL の分解から始めて、3 種類のルーティングとクエリパラメーター、最後に CORS までを 1 ステップずつ動かしながら学びます。

はじめかた

cd url-routing-cors-learning
node server.js
# → http://localhost:3000/ をブラウザで開く

依存パッケージはありません（Node.js 18 以上）。サーバー必須 の付いたステップは server.js 経由で開いてください。file:// や python -m http.server では再現できません。

📽 解説スライドを開く

  • 01URL の構造を分解するprotocol / host / port / pathname / search / hash / origin。URL オブジェクトと location
  • 02クエリパラメーターで情報を渡すURLSearchParams・form GET・エンコード・ページ間の受け渡し・状態を URL に保存
  • 03サーバーサイドルーティングサーバー必須パスごとにサーバーが HTML を返す。毎回フルリロード。:id パラメーター・404
  • 04ハッシュルーティング#/users/42。hashchange イベント。サーバーにリクエストが飛ばない SPA
  • 05History API ルーティングサーバー必須pushState / popstate。きれいな URL と、リロード時に必要なサーバー側フォールバック
  • 06CORS の基本サーバー必須同一オリジンポリシー。Access-Control-Allow-Origin。ブロックされてもリクエストは届いている
  • 07CORS 応用（実コード）サーバー必須プリフライト・独自ヘッダー・Expose-Headers・Cookie (credentials)・よくある失敗

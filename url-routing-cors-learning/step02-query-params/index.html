STEP 02

クエリパラメーターで情報を渡す

?key=value&key2=value2 は、ページ（やサーバー）に「追加の情報」を渡すための仕組みです。

1. フォームで別ページに値を渡す（JS なし）

<form method="get"> は入力値を自動でクエリパラメーターにして、action のページへ移動します。

<form action="receive.html" method="get">
  <input name="name"> <select name="lang">…</select>
  <input type="checkbox" name="tag" value="html"> <input type="checkbox" name="tag" value="js">
</form>
// 送信すると次の URL に移動する（スペースは + 、日本語は %XX にエンコード）
receive.html?name=%E5%B1%B1%E7%94%B0+%E5%A4%AA%E9%83%8E&lang=ja&tag=html&tag=js

2. JavaScript でリンクを組み立てて渡す

文字列連結ではなく URLSearchParams を使うと、エンコードを自動でやってくれます。

❌ そのまま連結
✅ URLSearchParams

❌ で開く✅ で開く

// ❌ & や = や # が値の中にあると、区切り文字と区別できなくなる
"receive.html?keyword=" + kw

// ✅ URLSearchParams がエンコードしてくれる
const params = new URLSearchParams({ keyword: kw, page: 1 });
"receive.html?" + params.toString()

// ✅ URL オブジェクトでも同じ
const url = new URL("receive.html", location.href);
url.searchParams.set("keyword", kw);

3. 画面の状態を URL に保存する（リロード・共有しても復元される）

絞り込み条件を URL に入れておくと、リロードしても、URL を他人に送っても同じ画面が出ます。

    現在の URL:
    条件を変えたあとにリロード（⌘R / F5）してみてください。

    // 読み込み時: URL → 画面
const p = new URLSearchParams(location.search);
cat.value = p.get("cat") ?? "";             // 無いときは null が返る
max.value = p.get("max") ?? "";

// 変更時: 画面 → URL（replaceState はリロードせず URL だけ書き換える）
const p = new URLSearchParams(location.search);
cat.value ? p.set("cat", cat.value) : p.delete("cat");
history.replaceState(null, "", "?" + p);

    4. URLSearchParams のよく使うメソッド

    const p = new URLSearchParams("?tag=html&tag=js&page=2");
p.get("page")       // "2"   ← 値は必ず文字列。数値にするなら Number()
p.get("none")       // null
p.getAll("tag")     // ["html", "js"]  ← 同名キーが複数あるとき
p.has("page")       // true
p.set("page", 3)    // 上書き
p.append("tag","css") // 追加
p.delete("tag")     // 削除
p.toString()        // "page=3"  ← 先頭の ? は付かない
Object.fromEntries(p) // { page: "3" }
    注意: クエリパラメーターは URL に丸見えです（履歴・サーバーログ・Referer に残る）。パスワードやトークンなどの秘密情報は入れないこと。

受け取り側のページ

このページは location.search を読んで、渡された値を表示しているだけです。

受け取った URL

location.search（生の文字列）
デコード後

URLSearchParams で読んだ結果

const p = new URLSearchParams(location.search);
p.get("name")     // 1 つだけ取得
p.getAll("tag")   // 同じ名前が複数ある場合は配列で
for (const [key, value] of p) { … }  // すべて列挙
受け取った値は ユーザーが自由に書き換えられる 入力です。表示するときは innerHTML ではなく textContent を使いましょう（XSS 対策）。
試しに URL の name を <img src=x onerror=alert(1)> にしても、このページでは文字として表示されるだけです。
